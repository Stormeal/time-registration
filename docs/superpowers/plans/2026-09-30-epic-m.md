- Use the `scripts/check.ps1` quality gate after implementation.
- Keep the original checkout's uncommitted changes untouched.

## Review Focus

- Adding a past lunch during an active session must retain the active work session and validate the lunch interval against its bounds.
- Completing a timer lunch during an active session must make it visible in the editor immediately.
- Scrolling the session editor must not change a Testhuset assignment through incidental wheel input.
- Disabled-action explanations must match the current state and not imply that an unavailable action can be used.
- The wider startup window and horizontal Today controls must remain usable at narrow window sizes.
